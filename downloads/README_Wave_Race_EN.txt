RETRO64LAB — WAVE RACE 64: DOLPHIN & ORCA MOD v1.0

THIS IS A PATCH FOR AN ORIGINAL GAME DUMP. NO COMMERCIAL GAME ROM IS INCLUDED.

REQUIRED ORIGINAL GAME
Wave Race 64 - Kawasaki Jet Ski (USA) (Rev 1 / Rev A)
Format: .z64 (big-endian)
Size: 8,388,608 bytes (8 MiB)
SHA-1: 508dfc2d4caa42b6f6de5263d0aed5e44ac7966a

INSTALLATION
1. Extract Retro64Lab_Wave_Race_Dolphin_Orca_v1.0.bps.
2. Open Floating IPS (Flips) or another BPS-compatible patcher.
3. Select "Apply Patch", then select the .bps file.
4. Choose your clean Wave Race 64 USA Rev 1 .z64 file.
5. Save as a NEW output file (do not overwrite your original dump).
6. Run the newly patched ROM using a compatible device or emulator.

VERIFY PATCHED OUTPUT
Expected modified ROM SHA-256:
6a71508e1bf529c93d146a3a49d545d3b4463c862eaefe9402a8e1622f69012c
BPS patch SHA-256:
565c551666bcbc3c3a161f97ee3ac13b1d31197bc5881e85afca8aa3a35d5212
If your patcher reports a source mismatch, do NOT force the patch.
PAL, USA Rev 0, Japanese, and previously modified ROMs are not supported.

CONTROLS WHEN CONFIRMING A RIDER (SINGLE PLAYER)
- D-pad DOWN + START: dolphin
- R button + START: orca
- START alone: normal jet ski

STATUS AND LIMITATIONS
- Single-player animal mod was tested by its creator on Analogue 3D.
- Independently selectable animals for both VS players are NOT part of v1.0.
- Failed experimental VS builds 02-05 are NOT included.
- The BPS was generated against the exact clean game dump and reapplied;
  its output matched the already-tested stable ROM BYTE FOR BYTE.
- File reproducibility does not prove compatibility with every emulator/device.

This package distributes only the BPS patch, not the commercial game ROM.
